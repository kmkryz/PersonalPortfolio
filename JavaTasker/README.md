# Overview

As a software developer, I am expanding my expertise in object-oriented programming by learning Java. This project allows me to understand Java's strong typing system, class structure, and file handling capabilities while creating practical, real-world applications.

I have developed a Task Management System that demonstrates core Java concepts including class inheritance, file I/O operations, and collection framework usage. The application allows users to create, manage, and track tasks with features like task creation, completion marking, and persistent storage.

My purpose in writing this software was to gain hands-on experience with Java's syntax and object-oriented principles while creating something useful. The project helped me understand Java's approach to file handling, data structures, and user input processing.

[Software Demo Video](https://youtu.be/fT269NBqb3k)

# Development Environment

- Visual Studio Code with Java Extension Pack
- Java Development Kit (JDK) 17
- Git for version control

The program is written in Java and utilizes several built-in Java libraries:

- java.util.ArrayList for dynamic task storage
- java.io for file operations
- java.util.Scanner for user input handling
